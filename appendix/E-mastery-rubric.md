# પરિશિષ્ટ E — Mastery rubric

"Expert" અહીં પદવી નથી; **અવલોકી શકાય તેવી કુશળતા** છે. દરેક હરોળમાં પોતાને પ્રામાણિકપણે મૂકો.

| કુશળતા | શિખાઉ | સક્ષમ | Expert |
|---|---|---|---|
| **સમજાવવું** | વાર્તાથી agent loop સમજાવે | વાર્તા વગર, સાચા શબ્દોમાં, બે invariants સાથે | નવું વર્તન જોઈને કહે કે તે કઈ invariant નું પરિણામ છે |
| **Trace** | Lab નો output વાંચે | એક સંદેશાનાં સ્ટેશન files સાથે કહે | અજાણ્યા feature ને `grep` થી entry point થી અંત સુધી trace કરે |
| **ખર્ચ** | Turn અને iteration જુદા પાડે | Cache ક્યારે તૂટે તે કહે | બિલ વધ્યું હોય ત્યારે ચાર પરિકલ્પના આપે અને દરેક કેવી રીતે ચકાસવી તે કહે |
| **વિસ્તારવું** | Skill લખે | Plugin tool + test લખે | Footprint ladder પરથી નક્કી કરે કે ક્ષમતા ક્યાં રહે, અને "ના" નું કારણ આપે |
| **Diagnose** | 🩺 ની યાદી અનુસરે | લક્ષણ પરથી સાચો થર (prompt / tool / memory / gateway) ઓળખે | Bug ની line બતાવે, અને ઇરાદો (`git log -S`) ચકાસે |
| **સલામતી** | Approval modes જાણે | Default deny, hardline, at-most-once સમજાવે | નવા feature માં "ભૂલ થાય તો કઈ બાજુ પડે?" પૂછે અને જવાબ design માં લખે |
| **પ્રામાણિકતા** | ✅ 🧪 ⚠️ નો અર્થ જાણે | પોતાના દાવામાં "વાંચ્યું" અને "ચલાવ્યું" જુદાં રાખે | Docs-vs-code ફરક શોધે, ચકાસે, અને repro સાથે report કરે |

## પોતાને ચકાસો

- **સક્ષમ:** પ્રકરણ 7 ની mastery પરીક્ષાના 6 માંથી 4 પ્રશ્ન પુસ્તક બંધ રાખીને.
- **Expert ની દિશામાં:** નીચેમાંથી એક ખરું કામ:
  1. Hermes install કરો અને આ પુસ્તકના દરેક ⚠️ command ને ચલાવીને [verification log](F-verification-log.md) માં ✅/❌ ઉમેરો.
  2. `mehmaan-tally` ને `hermes plugins doctor --ci` માંથી પસાર કરો.
  3. પ્રકરણ 1 ના docstring drift માટે upstream PR: "the exact line", એક વાક્યનું કારણ.

પુનરાવર્તનનું સમયપત્રક: દરેક પ્રકરણનાં "પુનરાવર્તન કાર્ડ" 1 દિવસ, 3 દિવસ, 7 દિવસ અને 21 દિવસ પછી.
